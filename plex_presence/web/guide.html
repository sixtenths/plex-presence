Plex Presence — start here

A step-by-step guide. No programming knowledge needed.

Show what you’re watching on Discord

Plex Presence watches your Plex playback and puts the title, episode, poster, and progress on your Discord profile. You can watch Plex on a TV, phone, tablet, or computer. The app follows the Plex account or profile you select.

You need a Plex account with access to a working Plex server and a Discord account. You do not need to own the Plex server. This app does not supply movies, a Plex subscription, a Plex server, or a Discord account.

The easiest choice: run Plex Presence on your Windows PC or Mac, open the Discord desktop app on that same computer, and choose Discord desktop. No developer registration or Discord authorization form is needed for that mode.

Use the app’s left sidebar to move between Overview for current activity, Connections for accounts and servers, Preferences for what you share, and Setup guide for these instructions. Choose Connections or Preferences whenever you need to do a step, then return to Setup guide. The chapter list jumps to a topic; Next walks through everything. Open connections takes you to the account controls when you are ready to do a step. In the optional headless browser interface, close the guide to reach setup and use Help / Setup guide to reopen it.

The desktop app starts on Overview. A new installation shows a compact checklist and a Start setup button to begin connecting your accounts. Walk me through it opens this detailed guide. Choose Setup guide in the sidebar whenever you want the full walkthrough. The optional headless browser interface can open this guide automatically and remembers its choice separately in that browser.

You’re ready if you can already watch something in Plex and sign into Discord.

Pick how to connect to Discord

Choose Connections in the left sidebar and find the mode selector in the Connect Discord section. In the headless browser interface, close the guide to reach that section.

Discord desktop — recommended for most people

Choose this if Discord runs on the same Windows, macOS, or Linux computer as Plex Presence. Open Discord and log into the account you want to use. Select Discord desktop, then click Apply connection mode. Plex Presence connects automatically.

  • You do not need a Discord developer application, client secret, bot token, or OAuth approval.
  • The public Plex Presence application ID supplies the app label. It does not sign you into the developer’s Discord account or connect you to their Plex server.
  • Plex Presence and Discord must both stay running on this computer. The Discord website in a browser does not provide the desktop connection.
  • Discord mobile apps on iOS/Android do not provide this local connection. For a Pi or an always-on machine without a Discord desktop app, use the other mode.

Always-on / no Discord client — advanced

Choose this for a Raspberry Pi or computer where Discord will not be running. It requires your own Discord developer application and a one-time authorization. The walkthrough for that is in chapter 7. It uses an undocumented publishing endpoint and can stop working if Discord changes it.

You can switch modes later. Existing installations that already connected through authorization keep Always-on mode when updated. Desktop mode is the default for new installations.

If you chose desktop mode, you can skip chapter 7 completely.

Sign into your Plex account

  1. Choose Connections in the left sidebar, then find the Plex controls.
  2. Click Connect Plex. This opens Plex’s own sign-in page in your system browser.
  3. Sign into the Plex account you normally use to watch. Use your usual Google, Apple, email, or other sign-in method. Do not put your password into Plex Presence.
  4. Approve the connection when Plex asks, then return to the Plex Presence application window. The app checks for the completed sign-in automatically.
  5. If the desktop app still says you are signing in, click Check sign-in. The headless browser interface calls this button I’ve signed in. If necessary, click Refresh servers or the refresh button beside the server list.
  6. If you watch under a different Home profile, do chapter 5 before continuing.
  7. If your account has exactly one accessible server and no saved selection, the app connects to it automatically. If several servers are available, open the Plex server dropdown, choose the server with your media, and click Use this server.

Refresh servers remembers your current server when it is still accessible, without disconnecting playback. If the old selection is no longer available, one accessible server is connected automatically; with several servers, you choose which one to use.

A server marked (shared) belongs to somebody else. That is fine: choose it if it is the one you watch from. Your access comes from your own Plex account, not the owner’s password or token.

If you have several servers, pick the one actually serving your movie or show. The server must be online and reachable from the machine running this app. Being able to sign into Plex does not guarantee that a particular server is reachable.

For ordinary setup, you can skip Direct connection…. The headless interface labels this Advanced: direct server connection. It is for people who already know their server address and Plex token. Do not ask a friend for their server-owner token just to use this app.

Success: the app shows “Selected:” followed by the correct server name.

Plex Home profiles and shared accounts

Someone shared their server with your regular Plex account

Use your own Plex sign-in and select their server marked (shared). You do not need to change Home profiles unless you actually watch as a different profile. Shared mode listens for playback notifications authorized for your account and locks the tracked username to that profile.

You select a named Home profile when opening Plex

  1. Sign into Plex first using a full account that belongs to that Plex Home.
  2. Choose Connections → Plex Home profiles to open the profile dialog. In the headless browser interface, expand Plex Home: choose a profile.
  3. Click Load Home profiles.
  4. Choose the same profile you select on your TV or Plex player.
  5. If the profile says PIN required, enter its four-digit PIN. This is the profile PIN, not the email password or a two-factor code.
  6. Click Use this profile. The PIN is used for this switch and is not saved.
  7. Switching profiles clears the previous server selection and refreshes the new profile’s servers. If only one is available, the app connects automatically. If several are available, choose one and click Use this server.

A managed profile does not have its own independent Plex login. An existing full member of its Home signs in first, then switches. You do not need the server owner’s token, but you must have normal Plex authorization to use that profile.

Start or resume playback after connecting. Shared mode receives new playback events. If a movie was already playing when the app started, pause and resume it so a fresh event arrives.

If no profiles load, check whether the account is actually in a Plex Home. A normal shared account can use a shared server without belonging to a Home. If a protected profile rejects the PIN, ask the person who manages that profile; this app does not bypass it.

Success: “Selected profile” is the person watching, and the server dropdown shows that profile’s accessible servers.

Connect to Discord desktop

  1. Install and open Discord desktop on the same computer running Plex Presence.
  2. Log into the Discord account where you want the activity to appear.
  3. In Plex Presence, choose Discord desktop and click Apply connection mode.
  4. Leave the custom Application ID at its default. The built-in public application ID is sufficient. To use your own, open Custom application ID… in the Desktop Discord section.
  5. Wait a few seconds. The status should say that Discord desktop is connected and waiting for playback.
  6. Start a movie or episode in Plex using the selected account/profile. Check your Discord profile.

If Discord is closed, Plex Presence retries automatically. You can minimize Discord or close its window if it remains running in the system tray; fully quitting Discord disconnects desktop mode.

If the app says it is connected but the activity is hidden, check Discord’s settings for sharing detected activity and your activity privacy choices. The wording and location can change between Discord versions. Make sure you are looking at the same Discord account that is signed into the desktop app.

On Linux, sandboxed packages such as Flatpak or Snap may isolate Discord’s local socket. If the connection fails despite Discord running, check that both apps run as the same OS user and that the package allows local Discord IPC. Do not run Plex Presence as administrator or root as a default fix.

You do not need to create a bot or visit the Developer Portal for the default desktop connection.

Always-on mode: the complete Discord setup

Skip this chapter if you chose Discord desktop. These steps are only for a Pi or another machine where the Discord desktop client will not run.

  1. Choose Always-on / no Discord client in the app and click Apply connection mode. The advanced authorization instructions will appear.
  2. Open the Discord Developer Portal in your browser and sign in.
  3. Click New Application. Give it a name such as Plex. Read and accept Discord’s terms if you agree, then create it.
  4. Open the application’s Social SDK → Getting Started page. Complete the activation form with accurate details and enable Social SDK. Discord may ask for your name, contact email, country, and project information. Use the details appropriate to your own project.
  5. Open OAuth2 in that application’s settings. Enable Public Client and save the change.
  6. In OAuth2’s redirect URLs, add this exact address: . Save it. The port and /callback ending must match. Use 127.0.0.1, not a different hostname.
  7. Find Application ID under the application’s general information. Copy that numeric ID.
  8. Return to Plex Presence and paste it into Discord Application ID.
  9. Read the permission note and check its box. Click Connect Discord.
  10. Check the account shown on Discord’s approval screen. If it is the wrong account, switch accounts before approving. Review the permissions, then authorize if you agree.
  11. Wait for Discord’s browser redirect to complete, then return to the Plex Presence window. Its Discord status should show that your account is linked. In the headless workflow, continue in the local browser interface instead.

You do not need a bot token, client secret, Discord password, or raw Discord account token. Never paste one of those into the Application ID field.

Discord bundles social/profile/friend/invite capabilities into the presence permission; read the actual consent screen. This app uses authorization refresh and activity publishing. The no-client publishing endpoint is undocumented and can change independently of this app.

Success: “Your Discord account is linked.” If you see invalid_scope, enable Social SDK on the same application ID, then reconnect.

Choose what appears, then test it

Choose Preferences in the left sidebar. In the optional headless browser interface, find Make it yours on the main page.

  • Plex user to track: choose the person actually watching. In shared mode this is locked to your signed-in profile. For an owner connection, the refresh button suggests users currently playing; you can also enter an exact username.
  • Share playback: the main on/off switch. Turn it off to stop publishing.
  • Show artwork: includes a poster when one is available. Turn it off to share no image.
  • Use your Plex artwork: enabled by default for new installations or when no choice has been saved. Existing saved choices, including off, are preserved after an update. It uses the exact poster selected on your Plex server by uploading that image to Litterbox (or TempFile.org if Litterbox is unavailable) for one hour, then fitting it through the image proxy so Discord can display it. Images are public to anyone with their URL; Plex credentials and server addresses are never sent to these services. Turn this setting off if you prefer public-provider artwork without uploading your server’s poster.
  • Show playback progress: sends the movie/episode timeline. Discord can still display its own activity duration even with this option off.

Click Save preferences after changing anything. In the headless browser interface, the equivalent switches are labeled Share my playback, Show poster artwork, and Use my selected Plex posters.

A quick test

  1. Play something for at least 15–20 seconds on the selected Plex profile.
  2. Look at the app’s preview and connection status. Then open your Discord profile to check the actual activity.
  3. Pause Plex. The Discord activity should disappear, rather than show a paused timer.
  4. Resume playback. The title and poster should return.
  5. Stop playback. The activity should clear again. Allow a few seconds for updates and Discord caching.

Anime shows tagged Anime in Plex use absolute episode labels. Numbering follows Plex’s metadata and regular-season order; specials stay separate. Existing absolute numbers are preserved. Missing or unusual Plex metadata can cause a fallback to season/episode labels.

Success: playing shows the correct item, pause hides it, resume restores it, and stop clears it.

Everyday use, closing, and updating

After the first setup, open Plex Presence and start watching. Your settings are stored locally. You do not need to repeat account setup every time unless authorization expires or you deliberately disconnect.

  • Closing the desktop window hides it and leaves Plex Presence running. Reopen the app shortcut or use the Windows tray icon to configure it again. Closing the optional headless browser tab also leaves its watcher running.
  • Quit application in the window, or Quit Plex Presence in the Windows tray menu, stops the watcher and requests that Discord clear the activity.
  • Turning off the computer stops the app. Desktop mode also needs Discord on that computer. For an always-on setup, run the app on a machine that stays on.
  • The Plex server must stay on too. A Pi running presence cannot serve the movies from a Plex server on a powered-off PC.
  • Windows startup at sign-in is enabled by the installer. You can uncheck that option or disable it in Windows Startup apps. macOS/Linux startup can be configured using the operating system’s login-item or service tools.

Windows background operation

The installer can start Plex Presence automatically when you sign in. It uses background mode, which keeps the application window hidden until you need it. Right-click its icon near the Windows clock to open the native settings window or quit. Windows may place the icon in the hidden-icons menu. Closing the window keeps sharing active. Launching the Start menu shortcut again brings the existing window back.

Get an update from inside the app

Using v0.2.x or an earlier version? Download and install v0.3.1 or later from the GitHub release page once to get the update button. Quit the old app before running the Windows installer or replacing the complete macOS/Linux app. Your saved account settings stay in their separate settings folder.

  1. If you changed any preferences, click Save preferences first.
  2. Click Check for updates near the bottom of the app’s sidebar. You can keep using your current version while it checks GitHub.
  3. The update window shows whether a newer stable version is available, along with its release notes.
  4. To install an available update, click Download and install. Wait while the package downloads and its checksum is verified. You can cancel during the download.
  5. Let the app close and finish updating. It waits for the current app to stop before replacing it, then reopens with the same accounts, saved preferences, and local port.

Windows: updates inside the app work for a copy installed through the Windows installer. macOS/Linux: keep the complete app in a folder your user can change; a read-only disk image or protected folder cannot be updated in place. If installation is unavailable, click Open GitHub release, quit the app, and download/install the matching package manually. Source-code copies can check for releases but are not replaced automatically. The optional headless browser interface uses the manual download method.

The app checks only when you choose Check for updates. It does not check at startup or install updates unattended. Checking alone changes nothing; you choose Download and install to proceed. Packages come from this project’s GitHub releases, and no Plex or Discord account tokens are sent in update requests. The checksum verifies the download but does not make the app code-signed or notarized.

Runtime dependencies are already bundled in the native downloads; installing extra Python packages is only necessary when running source code.

Need this guide again? Choose Setup guide in the app’s left sidebar. The headless browser interface has a Help / Setup guide button.

Something went wrong? Start here

“Could not reach Discord desktop”

Open the installed Discord desktop app, sign in, and keep it running on the same computer. Discord in a browser or on your phone is not enough for desktop mode. Allow a few seconds for the next retry. If you are using a Pi without Discord, choose Always-on mode instead.

The app will not start, or its window is missing

Wait a few seconds after launching. If the app is already running in the background, launch its shortcut again or use the Windows tray menu to show the existing window. On Linux, ensure you extracted the complete folder, the executable can run, and a graphical desktop is available. Source installations need the Qt runtime installed by pip install . and any Qt system libraries required by your Linux distribution. For a machine without a graphical session, use --no-browser and the Pi/headless chapter. A conflicting local port can also prevent startup; advanced users can choose another --port, and Always-on authorization must use the matching redirect URL.

The update button is missing or installation is unavailable

Versions before v0.3.1 need one manual download to get Check for updates. If the update window offers Open GitHub release instead of installation, use the matching installer/archive from that page. Windows must be installed through its installer, and macOS/Linux need a writable app folder. Keep the saved settings folder separate from the app folder. A failed download or checksum check does not install that package; retry later or use the official release page.

Plex signed in, but the server is missing

Make sure you used the correct Plex account and Home profile. Click the refresh button by the server dropdown. Ask the server owner to confirm that your own account/profile has library access and that the server is online. Do not replace your token with somebody else’s owner token.

Shared server selected, but no playback appears

Pause and resume the player after connecting. Check that the player uses the same profile selected here. The app needs a reachable notification connection and fresh playback events. If those are denied or unavailable, it will not invent a playback status.

Discord authorization says “invalid_scope”

For Always-on mode, enable Social SDK in the Developer Portal for the exact Application ID entered here. Public Client alone is not sufficient. Then try Connect Discord again.

Discord code exchange or redirect error

Check Public Client, save the exact redirect , and confirm the port. If you restarted the app while signing in, start Connect Discord again: the previous one-time login request may have expired.

The wrong image appears, or no image appears

Enable Show artwork. Use your Plex artwork is on by default for new setups; an older saved off choice remains off. Enable it and save if you want to switch to the server’s selected cover. Poster changes may take up to five minutes to refresh. Image-host or proxy failures can temporarily remove artwork; the activity can still work without it.

The wrong user’s playback or wrong Discord account appears

Check the selected Plex Home profile and tracked username. Desktop mode uses whoever is signed into Discord desktop. Always-on mode uses the account that approved authorization; disconnect and authorize the intended account again.

Reporting a problem

Use GitHub Issues. Include your OS, app version, connection mode, the visible error, and what you were doing. Do not attach configuration files, tokens, PINs, passwords, or full authorization callback URLs.

Run it on a Pi or remote machine

This is the advanced path for a machine without a graphical desktop. Normal desktop installs use their own native application window. The Pi/headless path deliberately keeps the optional localhost browser interface so you can configure the remote machine through an SSH tunnel. The Pi needs a supported 64-bit Linux OS, internet access, and network access to the Plex server.

  1. Download the Linux ARM64 archive for a 64-bit Pi and extract the entire folder.
  2. Start its executable with --no-browser. For example, from the extracted directory: ./PlexPresence --no-browser.
  3. On your desktop, open a terminal and create an SSH tunnel. Replace the example username and machine name with your own:
    ssh -N -L 8765:127.0.0.1:8765 user@your-pi
  4. Leave that terminal open while setting up. In your desktop browser, open http://127.0.0.1:8765.
  5. Choose Always-on mode and follow its Discord setup chapter. The SSH tunnel lets Discord’s callback reach the app on the Pi.
  6. Connect Plex, choose the profile/server, and test playback. After setup, the tunnel is only needed when viewing settings or authorizing again. The app process itself must keep running on the Pi.

For unattended operation, configure your preferred Linux service manager to run the app as your regular user. Closing an ordinary SSH session can stop a process launched inside it; this download does not automatically create a system service.

If 8765 is already used locally, run the app with --port 8790, forward 8790 at both ends, browse to that port, and save the corresponding redirect URL in Discord. Do not expose the setup port directly to the public internet.

Desktop mode on a remote machine only works if a compatible Discord desktop client is running on that same machine and OS user session. A Discord app on your separate PC cannot provide local IPC to the Pi.

What stays on your device

Your settings and account tokens are kept in your OS user profile: %LOCALAPPDATA%\PlexPresence on Windows, ~/Library/Application Support/PlexPresence on macOS, or ~/.config/plex-presence on Linux unless XDG_CONFIG_HOME changes it. These are private plaintext files, not an encrypted keychain. Never share them.

Desktop mode uses local Discord IPC and needs no Discord OAuth token. Always-on mode stores the authorization tokens locally. Plex Home PINs are not saved. Home switching retains the initial Plex login token so you can switch profiles later.

There is no central Plex Presence account or analytics backend. New setups use the selected Plex poster by default: the image is uploaded to Litterbox (or TempFile.org if Litterbox is unavailable) for one hour and fitted through the image proxy. Discord and the proxy may cache it beyond the host’s expiry. Images are public to anyone with their URL; Plex credentials and server addresses are never sent to these services. Existing saved preferences are preserved. Turn off Use your Plex artwork to use public-provider image URLs instead, or turn off Show artwork to avoid artwork requests entirely.
