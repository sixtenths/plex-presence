✓ Your Discord account is linked.

One-time setup: create your own Discord application. This mode uses your own application and your own Discord sign-in.

  1. Open the Discord Developer Portal ↗ and create an application, for example “Plex.”
  2. Complete Social SDK → Getting Started for your app. Discord requires this for presence permission.
  3. Under OAuth2, enable Public Client, add this exact redirect URL, and save.
http://127.0.0.1:8765/callback

Sign in and approve on Discord. Never paste a Discord account token or password here.

A few things to know

Your settings and account tokens are stored locally in your OS user profile. This app and your Plex server need to stay running. Closing this browser tab is fine; use Quit below to stop the app.

Client-free Discord publishing uses an undocumented endpoint and may stop working if Discord changes it. Shared servers use playback notifications from your signed-in account. Start or resume playback after connecting; server access is still required. Public artwork is fetched through wsrv.nl; no Plex token is sent there. Selected-poster mode uploads your chosen image to Litterbox (or TempFile.org if Litterbox is unavailable) for 1 hour. Disable artwork if you prefer.
